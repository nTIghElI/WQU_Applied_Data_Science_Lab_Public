# 🏡 Housing Price Analysis in Mexico

This project is part of the **Applied Data Science Lab** at [WorldQuant University](https://www.worldquantuniversity.org/), a free, online program focused on real-world data science skills.

## 📊 Project Overview

Using a dataset of **21,000 properties for sale in Mexico** from Properati.com, this project investigates whether **property prices are more strongly influenced by size or location**.

Students apply core data science techniques to:
- Import and clean CSV data using the `pandas` library
- Organize information with Python data structures
- Create visualizations (scatter plots, box plots)
- Perform correlation analysis to explore variable relationships

## 🔍 Research Question

> Are property prices in Mexico more strongly influenced by **size** or **location**?

## 🛠️ Tools & Technologies

- Python 3
- pandas
- matplotlib
- Jupyter Notebook or equivalent IDE

## 📈 Key Visualizations

- **Scatter Plot**: Surface area vs. price
- **Box Plot**: Price distribution across locations
- **Correlation Matrix**: Quantifying relationships between variables
